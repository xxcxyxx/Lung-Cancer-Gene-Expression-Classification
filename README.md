# Lung Cancer Gene Expression Classification

## 유전자 발현 데이터 기반 폐암 아종 분류 딥러닝 프로젝트

TCGA 폐암 유전자 발현 데이터를 활용해 폐암 아종을 분류하고, 데이터 증강 기반 2단계 학습 구조를 적용해 분류 성능 개선을 실험한 프로젝트입니다.

본 프로젝트는 고차원 유전자 데이터의 전처리, 암 관련 유전자 선택, 데이터 증강, 딥러닝 모델 학습, 실험 결과 비교까지 포함한 연구형 데이터 분석 프로젝트입니다.  
단순히 모델을 학습하는 데 그치지 않고, 소량·고차원 데이터 환경에서 데이터 증강과 학습 전략이 모델 성능에 어떤 영향을 주는지 확인하는 데 초점을 두었습니다.

## 2. Project Overview

유전자 발현 데이터는 하나의 샘플에 수많은 유전자 변수가 포함된 고차원 데이터입니다.  
반면 의료 데이터는 수집 가능한 샘플 수가 제한적인 경우가 많아, 모델 학습 과정에서 과적합이나 일반화 성능 저하가 발생할 수 있습니다.

이 프로젝트에서는 이러한 문제를 해결하기 위해 데이터 증강을 활용했습니다.  
다만 증강 데이터를 최종 학습에 직접 사용하는 경우 원본 데이터의 분포가 왜곡될 수 있다고 판단해, 증강 데이터는 pre-training 단계에서 활용하고 최종 fine-tuning은 원본 데이터만으로 수행하는 2단계 학습 구조를 설계했습니다.

---

## 3. Problem Definition

이 프로젝트의 목표는 폐암 환자의 유전자 발현 데이터를 기반으로 폐암 아종을 분류하는 것입니다.

- **Input**: 암 관련 유전자 발현값
- **Target**: 폐암 아종 class
- **Task Type**: Multi-class Classification
- **Main Challenge**: 고차원 변수 대비 제한적인 샘플 수
- **Approach**: 데이터 증강 기반 pre-training과 원본 데이터 기반 fine-tuning

## 5. Data Preprocessing

모델 학습 전 다음과 같은 전처리를 수행했습니다.

### 5.1 Gene Selection

원본 데이터에는 19,977개의 유전자 변수가 포함되어 있었습니다.  
모든 유전자를 그대로 사용할 경우 차원의 수가 지나치게 커지고, 모델이 노이즈에 영향을 받을 가능성이 있다고 판단했습니다.

따라서 암 관련 유전자 323개를 선별해 모델 입력 변수로 사용했습니다.

### 5.2 Log2 Transformation

유전자 발현값의 분포 차이를 완화하기 위해 log2 변환을 적용했습니다.  
이를 통해 극단적으로 큰 발현값의 영향을 줄이고, 데이터 분포를 안정화했습니다.

### 5.3 Z-score Normalization

유전자별 발현값의 스케일 차이를 줄이기 위해 z-score 정규화를 수행했습니다.  
정규화를 통해 각 feature가 모델 학습 과정에서 비슷한 기준으로 반영될 수 있도록 했습니다.

---

## 6. Methodology

## 6.1 Data Augmentation

소량 데이터 환경에서 모델의 학습 안정성을 높이기 위해 통계 기반 데이터 증강 방법을 적용했습니다.

증강 데이터는 원본 데이터의 클래스 정보를 고려해 생성했으며, 모델이 더 다양한 학습 패턴을 경험할 수 있도록 활용했습니다.

### Augmentation Strategy

- 클래스 기준 샘플링
- 샘플 평균 기반 생성
- 혼합 샘플 생성
- 원본 데이터 분포를 고려한 증강 데이터 구성

---

## 6.2 Two-stage Training Strategy

증강 데이터를 최종 학습에 직접 사용할 경우, 원본 데이터의 실제 분포와 다른 패턴이 모델에 과도하게 반영될 수 있습니다.

이를 줄이기 위해 다음과 같은 2단계 학습 구조를 설계했습니다.

### Stage 1. Pre-training

- 원본 데이터와 증강 데이터를 함께 사용
- 모델이 다양한 패턴을 먼저 학습하도록 구성
- 초기 가중치 학습 단계로 활용

### Stage 2. Fine-tuning

- 원본 데이터만 사용해 최종 학습
- 증강 데이터로 인한 왜곡 가능성 완화
- 실제 데이터 분포에 맞게 모델을 조정

이 구조를 통해 증강 데이터의 장점은 활용하면서, 최종 모델이 원본 데이터에 더 적합하게 학습되도록 설계했습니다.

## 7. Modeling

본 프로젝트에서는 MLP 기반 딥러닝 모델을 중심으로 폐암 아종 분류 모델을 구현했습니다.

또한 실험 과정에서 다양한 머신러닝 모델과 성능을 비교해, 제안한 2단계 학습 구조의 효과를 확인했습니다.

### Compared Models

- Logistic Regression
- Random Forest
- SVM
- XGBoost
- LightGBM
- MLP

### Main Model

- PyTorch 기반 MLP
- 입력층: 암 관련 유전자 323개
- 출력층: 폐암 아종 class
- 학습 방식: pre-training 후 fine-tuning

## 8. Experiment

### Validation Strategy

- Stratified 10-fold Cross Validation 적용
- 클래스 분포를 고려해 train/validation split 구성
- Baseline MLP와 제안 방식의 성능 비교

### Experiment Design

| 실험 | 설명 |
|---|---|
| Baseline MLP | 원본 데이터만 사용해 MLP 모델 학습 |
| Augmentation + MLP | 증강 데이터를 포함해 모델 학습 |
| Two-stage Training | 증강 데이터로 pre-training 후 원본 데이터로 fine-tuning |

## 9. Results

최종 모델은 정확도 88.32%를 기록했습니다.  
Baseline MLP 대비 약 1%의 성능 향상을 확인했습니다.

| 모델/방식 | 결과 |
|---|---:|
| Baseline MLP | 기준 모델 |
| Proposed Two-stage Training | 88.32% |
| 성능 변화 | Baseline MLP 대비 약 1% 향상 |

### Result Interpretation

성능 향상 폭은 크지 않지만, 소량·고차원 의료 데이터 환경에서 데이터 증강 기반 학습 전략이 모델 성능 개선에 기여할 수 있음을 확인했습니다.

특히 증강 데이터를 최종 학습에 직접 사용하는 대신, pre-training 단계에서 활용한 뒤 원본 데이터로 fine-tuning하는 구조가 원본 데이터 분포를 유지하면서 학습 안정성을 높이는 데 도움이 되었습니다.

## 10. Key Findings

### 1) 고차원 데이터에서는 feature selection이 중요함

원본 데이터는 19,977개의 유전자를 포함하고 있어, 전체 변수를 그대로 사용할 경우 모델이 노이즈에 민감해질 수 있습니다.  
암 관련 유전자 323개를 선별해 입력 변수로 사용함으로써 학습에 필요한 정보를 중심으로 데이터를 구성했습니다.

### 2) 데이터 전처리는 모델 성능의 기반이 됨

log2 변환과 z-score 정규화를 통해 유전자 발현값의 분포와 스케일 차이를 줄였습니다.  
이를 통해 모델이 특정 feature의 절대적인 크기에 과도하게 영향을 받지 않도록 했습니다.

### 3) 증강 데이터는 학습 안정성에 기여할 수 있음

소량 데이터 환경에서는 모델이 충분한 패턴을 학습하기 어렵습니다.  
증강 데이터를 pre-training 단계에서 활용함으로써 모델이 더 다양한 패턴을 먼저 학습할 수 있도록 했습니다.

### 4) 의료 데이터에서는 증강 데이터 활용 방식이 중요함

증강 데이터를 최종 학습에 그대로 사용할 경우 원본 데이터 분포가 왜곡될 수 있습니다.  
따라서 본 프로젝트에서는 증강 데이터로 먼저 pre-training을 수행하고, 이후 원본 데이터로 fine-tuning하여 최종 모델을 조정했습니다.

### 5) 단순 정확도보다 실험 설계가 중요함

최종 정확도는 88.32%였고 Baseline MLP 대비 약 1% 향상되었습니다.  
이 결과를 통해 단순히 모델 구조를 복잡하게 만드는 것보다, 데이터 특성에 맞는 학습 전략을 설계하는 과정이 중요하다는 점을 확인했습니다.
